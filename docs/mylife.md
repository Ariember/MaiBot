# 麦日常

麦日常内置于 MaiBot，可在 WebUI 侧边栏的“麦日常”分组管理日程、天气、关系与重要日期、联网见闻和主动私聊。

## 启用与配置

1. 打开“麦日常 → 日常配置”。模块默认关闭，配置完成后再启用。
2. 填写管理员 QQ 号，在私聊用户资料中添加需要维护关系的用户，并启用对应档案。
3. 按需调整群聊名单、回复概率、工作时间与联网见闻。主动私聊统一使用“主动私聊”中的全局开关，仍遵守用户每日额度、免打扰和工作时间。
4. 保存配置后启用麦日常。模型任务沿用主程序已有配置，可在日常配置中指定各项任务。

启用麦日常后，日程、生活状态和关系背景会参与已启用用户的聊天上下文，话题连续性沿用主程序的对话上下文与摘要。主人专属称呼在“私聊用户”中管理。新闻整理与主动判断会调用模型，实际用量可在管理页面查看。

## 管理页面

| 页面 | 内容 |
| --- | --- |
| 日常配置 | 可视化编辑、保存、重置与启停 |
| 麦麦此刻 | 当前生活场景、今日日程、天气与模型用量 |
| 记忆与牵挂 | 用户关系、重要日期与联网见闻 |
| 系统与配置 | 运行诊断、主动私聊候选与配置状态 |

启用并完成加载后，三个管理页面会出现在侧边栏；关闭时仍可打开日常配置。

## 配置与数据

所有路径相对于 MaiBot 的实例目录。Docker 部署对应已有的插件数据挂载目录。

| 路径 | 内容 |
| --- | --- |
| `data/plugins/fraternity-z.mai-mylife/config.toml` | 可视化配置保存位置 |
| `data/plugins/fraternity-z.mai-mylife/mai_life.db` | 日程、关系、联网见闻与用量等记录 |

备份时先停止实例，再复制整个 `data/plugins/fraternity-z.mai-mylife/` 目录。

## 从独立插件切换

内置版本沿用 `fraternity-z.mai-mylife` 标识，可继续使用该标识下的持久数据。停止 MaiBot 后，将原插件目录从 `plugins/` 移出，避免重复 ID 阻止加载；保留原目录作为备份。

如需沿用原配置，在内置版本首次启动前，将原插件的 `config.toml` 复制到 `data/plugins/fraternity-z.mai-mylife/config.toml`。不要覆盖已在内置页面保存的新配置。启动后在日常配置中核对启用状态、用户和模型任务。

## 已知限制

- 用户与群组功能面向 QQ，需要对应适配器和真实聊天会话。
- 运行状态、天气和联网见闻依赖相应服务可用；模型任务需在主程序中完成配置。
- 内置代码随 MaiBot 更新，不通过插件市场卸载或更新。
